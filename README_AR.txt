المساعد البيطري — مشروع Android مع دعم أصلي لاختيار الملفات

هذا المشروع يحتفظ بملفات نسخة Vet Assistant v69 الأصلية داخل app/src/main/assets، بما فيها الأقسام والموارد، ويضيف غلاف Android يستخدم WebView مع تنفيذ onShowFileChooser لفتح منتقي ملفات النظام.

بناء APK آلياً:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2) افتح تبويب Actions وشغّل Build Vet Assistant APK (أو ادفع commit إلى main/master).
3) بعد انتهاء البناء، افتح نتيجة التشغيل ونزّل artifact المسمى vet-assistant-apk.
4) فك ضغط artifact وثبّت app-debug.apk على الهاتف.

مهم: لم يُبنَ APK أو يُختبر على جهاز Android داخل هذه البيئة. ملف المشروع يهيئ البناء الآلي، لكن يجب التحقق من نجاح بناء GitHub ومن سلوك الملفات على الهاتف. لا تستبدل تطبيقك الحالي قبل اختبار النسخة الجديدة.
